Современная минималистичная социальная сеть, созданная на Flask. Публикуйте посты, общайтесь в комментариях, подписывайтесь на друзей и делитесь моментами своей жизни.

 ✨ Возможности

- 📝 **Публикация постов** с текстом и изображениями
- ❤️ **Система лайков** для оценки контента
- 💬 **Комментарии** под постами
- 👤 **Профили пользователей** с аватарами и био
- 👥 **Подписки** на других пользователей
- 📊 **Статистика** (посты, лайки, подписчики)
- 🔥 **Сортировка** постов (новые / популярные)
- 📱 **Адаптивный дизайн** для мобильных устройств
- 🔒 **Авторизация** и безопасность паролей
- 🖼️ **Загрузка изображений** с оптимизацией

### Предварительные требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
